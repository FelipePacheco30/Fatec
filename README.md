# 🎓 Atividades da FATEC – DSM

Este repositório reúne todas as atividades, exercícios e projetos desenvolvidos ao longo do curso de **Desenvolvimento de Software Multiplataforma (DSM)** na **FATEC**.  
Os arquivos estão organizados por semestre e por disciplina, facilitando a navegação e a consulta.

---

## 📂 Estrutura de Pastas

A estrutura segue o padrão:

Fatec/
 ┣ 1DSM/                     ← Primeiro semestre
 ┃ ┣ Engenharia de Software/
 ┃ ┣ Sistemas Operacionais/
 ┃ ┣ Algoritmos/
 ┃ ┣ Design Digital/
 ┃ ┣ Modelagem de Banco de Dados/
 ┃ ┗ Desenvolvimento Web/
 ┣ 2DSM/                     ← Segundo semestre
 ┃ ┗ ... (disciplinas do semestre)
 ┣ 3DSM/                     ← Terceiro semestre
 ┃ ┗ ...

### 🔎 Como navegar
- **`Fatec/1DSM`** → contém todas as disciplinas do **1º semestre**.  
- **`Fatec/2DSM`** → contém todas as disciplinas do **2º semestre**.  
- **Cada disciplina** possui sua pasta própria com atividades, exercícios e projetos organizados.  

---

## 🚀 Objetivo

Este repositório serve como:
- Material de estudo e consulta.  
- Registro de evolução ao longo do curso.  
- Base para revisão antes de provas e projetos integradores.  

---

## 📖 Observação

Os códigos e atividades aqui presentes foram desenvolvidos **para fins acadêmicos** e podem não representar soluções finais ou de produção.
