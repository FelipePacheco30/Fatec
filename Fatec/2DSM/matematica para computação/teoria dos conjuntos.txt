===============================
 TEORIA DOS CONJUNTOS
===============================

 Alfabeto
- Probabilidade:
  P(C) + P(C barrado) = 1 (100%)

Exemplo de conjuntos:
- c = {a, b, c}
- C = {d, e, f, ...}

O conjunto representa um agrupamento, e tudo fora dele é o "resto".

---

 Mandelbrot Set
- Exemplo 1:
  A = {1, 2, 3}
  B = {1, 3, 2}

  → Se pegarmos qualquer elemento de A ou de B, ele também estará no conjunto oposto.
  → Exemplo: "1" está em A e também em B, independente da ordem.
  ✔ Ou seja: A = B

- Exemplo 2:
  A = {1, 2, 3}
  B = {1, 3, 2, 4}

  → A ⊂ B (A é subconjunto de B, pois todos os elementos de A estão em B).
  → Mas B não é subconjunto de A.

---

 Cardinalidade
- P(A) = 2^|A|  (2 elevado à cardinalidade de A).
- Representa o número total de subconjuntos possíveis.

Exemplo:
A = {Ana, Pedro, Fabrício}
→ P(A) = 2³ = 8 subconjuntos

Tabela de subconjuntos:
{}  
{Ana}  
{Pedro}  
{Fabrício}  
{Ana, Pedro}  
{Ana, Fabrício}  
{Pedro, Fabrício}  
{Ana, Pedro, Fabrício}  

---

➕ União de Conjuntos (A ∪ B)
- Une todos os elementos, sem repetição.

Exemplo:
A = {1, 2, 3}  
B = {1, 2, 4, 7}  
A ∪ B = {1, 2, 3, 4, 7}

---

 SQL e Conjuntos
- UNION → Une os resultados de SELECTs.
  Exemplo:
    SELECT * FROM usuario WHERE nome = 'fabricio'
    UNION
    SELECT * FROM usuario WHERE nome = 'pedro';

- JOIN → Combina tabelas.
  Representação:
    [x] [+] [x]

- NATURAL JOIN → Combina tabelas automaticamente pelos campos em comum.
  Exemplo:
    SELECT * FROM usuario NATURAL JOIN cidade;

- EXCEPT → Exclui elementos de um conjunto em relação a outro.
  Exemplo:
    SELECT * FROM usuario
    EXCEPT
    SELECT * FROM usuario WHERE nome = 'fabricio';

- LEFT JOIN e RIGHT JOIN → Permitem manter todos os dados de uma tabela, mesmo sem correspondência na outra.
