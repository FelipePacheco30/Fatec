TEORIA DE CONJUNTOS E CONJUNTOS NUMÉRICOS

----------------------------------------------------
1. Conceitos Básicos
- Conjuntos: coleção de elementos.
- Dados de um conjunto NÃO são homogêneos (podem ser de naturezas diferentes).
- Representação:
  * Conjunto → letra MAIÚSCULA (ex: A, B, C).
  * Elemento → letra minúscula (ex: a ∈ A).
- Conjunto não considera repetição.
- Conjunto não possui ordem nem posição definida.
- Conjunto pode conter “qualquer coisa” (números, objetos, etc.).

----------------------------------------------------
2. Notação e Operações
- Enumerar: listar os elementos do conjunto em sequência.
- Set-builder: descreve as propriedades dos elementos, sem listá-los.
  Exemplo: A = {x ∈ N | x é par}.

- Complemento:
  A = {1, 2, 3}
  A' = {4, 5, 6}
  (A' é tudo o que NÃO está em A, dentro do universo U).

- Universo (U):
  Conjunto de todos os elementos possíveis em um contexto.
  U representa “100%”.

----------------------------------------------------
3. Conjuntos Numéricos
N = Naturais = {1, 2, 3, ...}
- Se incluir 0, então N = {0, 1, 2, 3, ...}.

Z = Inteiros = {..., -2, -1, 0, 1, 2, ...}

Q = Racionais
- Números que podem ser representados como fração p/q, com q ≠ 0.
- Incluem decimais exatos e dízimas periódicas.
- Exemplo: 1/3 = 0,333...

R = Reais
- Incluem racionais (Q) e irracionais (R - Q).
- Irracionais: números que NÃO podem ser representados como fração (ex: √2, π).

Observações:
- Comparação entre reais muitas vezes é feita olhando sinal → expoente → mantissa.
- Em computadores, se a diferença for muito pequena entre números grandes e pequenos, pode ocorrer perda de precisão (limite de bits, ex: 2^8).

----------------------------------------------------
4. Propriedade de Fechamento (Closure)
- Uma operação é fechada em um conjunto se, ao aplicar a operação entre dois elementos do conjunto, o resultado também pertence a esse conjunto.

Exemplos:
- N (naturais) é fechado para soma e multiplicação.
  (a + b = c, com c ∈ N).
- Z (inteiros) é fechado para soma, subtração e multiplicação.
- Q (racionais) é fechado para soma, subtração, multiplicação e divisão (exceto divisão por zero).

----------------------------------------------------
5. Operadores Lógicos
- E = ∧
- OU = ∨
- NÃO = ¬

----------------------------------------------------
6. Observações Extras
- Em Python, índices negativos percorrem listas ao contrário.
- Tipos de números usados em cálculos:
  * Pré-calculados (ex: constantes como π).
  * Dízimas periódicas → representadas como frações racionais.
- Em cálculos computacionais com floats, sempre haverá uma diferença mínima entre representações devido à limitação de bits.

----------------------------------------------------
7. Resumo dos Conjuntos Numéricos
N = Naturais → {0, 1, 2, 3, ...} (se não incluir 0, começam em 1).
Z = Inteiros → {..., -2, -1, 0, 1, 2, ...}.
Q = Racionais → frações p/q (dízimas e decimais exatos).
R = Reais → racionais + irracionais.
R - Q = Irracionais → √2, π, e, etc.
